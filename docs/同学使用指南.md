# 预推免填表助手 · 同学使用指南（转发版）

## 一、安装（2 分钟）

1. 把压缩包**解压**成一个文件夹（右键 → 全部解压缩），记住文件夹位置；
2. 打开 Edge，地址栏输入 `edge://extensions` 回车；
3. 打开左下角「**开发人员模式**」开关；
4. 点「**加载解压缩的扩展**」，**选择刚才解压出来的那个文件夹**（里面能看到 manifest.json 的那一层）；
5. 工具栏出现蓝色"推"字图标 → 点旁边的拼图图标 → 找到「预推免填表助手」点**图钉 📌 固定**。

> Chrome 同样适用：`chrome://extensions`，步骤一样。

## 二、录入档案（一次性，10 分钟）

1. 点工具栏「推」图标 → 「📝 打开档案编辑器」；
2. 按栏目填：基本信息、教育背景、四六级（**含取得时间**）、获奖、科研/竞赛、社会实践、家庭主要成员、自我陈述（建议多版本）、**报考意向**（目标学校/学院/专业/方向/导师）；
3. 顶部黄色横幅会提示还有哪些常用项没填，点条目可直达；
4. 点「💾 保存档案」。

> 想先试效果：点「🎲 生成测试数据」，到报名页试填，确认无误后再替换成真实信息。

## 三、日常使用（30 秒/学校）

1. **自己手动登录**目标学校报名系统（验证码、短信都自己来，工具不碰这些）；
2. 进入填表页面 → 右侧会自动出现悬浮面板（没出现就点扩展图标 →「在当前页显示悬浮面板」）；
3. 点「⚡ **一键填充**」→ 已识别字段自动写入；
4. 检查颜色：🟢绿色=已填好；🔴红色=需人工（如申请学院）；🟡黄色=档案没填（回编辑器补）；
5. 红色项人工处理：点「📋 **复制漏填项**」逐项粘贴（弹窗选择框会尽量自动点选，点不上的自己选一下）；
6. **人工核对 → 人工点提交**。

## 四、进阶功能

- **📥 从本页提取档案**：你在某个学校已经手填过的信息，点这个按钮直接搬进本地档案，以后别的学校复用；
- **📋 复制漏填项**：把没填上的字段和目标值复制到剪贴板，方便逐项粘贴；
- **🛠 复制字段报告**：遇到填不上的新系统，把这个报告发给作者改进（不含你的个人信息）；
- **备份**：编辑器里「导出 JSON 备份」，换电脑时「导入 JSON」。

## 五、常见问题

- **面板不出现？** 浏览器内置页面（edge:// 开头）和商店页面不支持；普通网页点扩展图标 →「在当前页显示悬浮面板」。
- **某字段没填上？** 正常：先「复制漏填项」手动贴，再发「字段报告」给作者。
- **数据安全吗？** 所有档案只存在你自己浏览器里，**不联网、不上传**；工具不会自动提交。
- **收到新版本？** 解压后**覆盖到原来那个文件夹的相同位置**（路径别变，否则档案对不上），然后在 `edge://extensions` 点该扩展的**刷新**按钮。

有填不上的学校 → 页面悬浮面板点「🛠 复制字段报告」发给作者，即可适配。
