# 预推免填表助手 · 使用说明（v1.15.4）

> 面向保研/推免学生的浏览器扩展：本地档案一次录入，多校报名系统一键填充。
> 支持 Edge / Chrome（Manifest V3）。

---

## 一、这是什么

参加预推免/夏令营时，同一份个人材料（姓名、身份证、学校、专业、排名、四六级、获奖、科研、经历、家庭成员……）要在几十所学校的报名系统里重复填写。「预推免填表助手」把你的材料保存在**你自己的浏览器里**，之后到任意学校报名页面点一下「⚡ 一键填充」，已识别的字段自动写入。

**三条铁律：**

1. 验证码、短信验证、登录：全部人工完成；
2. 只自动填基本信息类字段，**绝不自动提交**，最后一步永远人工；
3. 数据只存本机浏览器，**不出本机、不上传、无统计代码**。

## 二、安装（开发模式加载）

### 2.1 准备

1. 解压收到的 `tuimian-autofill-v1.15.4.zip`，得到 `dist` 文件夹；
2. 把 `dist` 文件夹放到一个**不会经常移动**的位置（移动后浏览器会找不到扩展，需要重新加载）。

### 2.2 Edge 浏览器

1. 地址栏输入 `edge://extensions` 回车；
2. 打开左下角「**开发人员模式**」开关；
3. 点击「**加载解压缩的扩展**」；
4. 选择解压出来的 **`dist`** 文件夹；
5. 工具栏出现图标后，点击右上角图钉 📌 固定图标。

### 2.3 Chrome 浏览器

1. 地址栏输入 `chrome://extensions` 回车；
2. 打开右上角「**开发者模式**」开关；
3. 点击「**加载已解压的扩展程序**」，选择 **`dist`** 文件夹。

### 2.4 更新新版本

收到新版本 ZIP 后：

1. 解压**覆盖**原来的 `dist` 文件夹内容；
2. 回到 `edge://extensions`（或 `chrome://extensions`），点本扩展卡片上的「**刷新/重新加载**」按钮；
3. 刷新目标报名页面（F5）。

> ⚠️ 重要：只覆盖文件不点「刷新」，运行的仍是旧版本。每次更新后必须刷新扩展 + 刷新页面。

## 三、首次使用：录入档案（一次性）

1. 点击浏览器工具栏的扩展图标 → 弹出小窗；
2. 点「**打开档案编辑器**」；
3. 逐项填写个人材料 → 点「💾 **保存档案**」。

### 3.1 档案各板块说明

| 板块 | 内容 | 说明 |
|---|---|---|
| 基本信息 | 姓名、性别、证件、出生日期、民族、政治面貌、籍贯、户口、地址、电话、邮箱、紧急联系人等 | 页面上的同名字段自动填写 |
| 教育背景 | 本科院校、学院、专业、学号、入学/毕业时间、GPA、成绩、专业排名/人数、四六级 | 四六级记得补「取得时间」，外语水平表要填 |
| 获奖情况 | 时间、地点、内容（每条一行，可多条） | 表格按 时间/地点/内容 逐行填，长文本自动汇总 |
| 学术成果 | 标题、类型、时间、排名、发表刊物 | 同上；表格自动「新增一行」逐条填 |
| 社会实践 | 时间、活动、职务、内容 | 汇总进长文本域 |
| 家庭主要成员 | 姓名、关系、单位、电话、政治面貌 | 表格逐行填 |
| 自我陈述 | 多版本（如 500 字/1000 字） | **不自动填**，复制粘贴 |
| 报考意向 | 申请学校、学院、专业、研究方向、学位类型、导师 | 页面上的申请类字段由此推导 |

### 3.2 小技巧

- 想先试效果：点「🎲 **生成测试数据**」一键生成随机假资料，到报名页试填，确认无误后再替换成真实信息；
- **备份**：编辑器里「导出 JSON 备份」，换电脑时「导入 JSON」；
- 「规则更新」默认关闭（开启后仅下载规则文件，不含个人数据），一般无需理会。

## 四、日常使用（约 30 秒/学校）

1. **自己登录**目标学校报名系统（验证码、短信全部人工）；
2. 进入**报名填表页**，右侧会自动出现悬浮面板（若未出现，请确认扩展已启用并刷新页面）；
3. 点「⚡ **一键填充**」→ 已识别字段自动写入（弹窗选择框会自动打开并点选，稍等几秒）；
4. 检查颜色高亮：
   - 🟢 绿色 = 已填好；
   - 🔴 红色 = 需人工（点「📋 复制漏填项」逐项粘贴）；
   - 🟡 黄色 = 档案里没填（回编辑器补）；
5. **人工核对 → 人工点提交**。

## 五、悬浮面板按钮详解

| 按钮 | 作用 |
|---|---|
| ⚡ 一键填充 | 自动填写当前页面所有可识别字段，含弹窗选择框自动点选、表格自动加行 |
| 🏫 学校目录（报名入口） | 收录 80+ 所高校推免/预推免报名入口，直达报名系统 |
| 🩺 提交前体检 | 扫描必填缺失、格式错误（身份证/手机/邮箱/邮编）、一致性风险（出生日期 vs 身份证、排名 vs 人数），点条目直接定位 |
| 📥 从本页提取档案 | 反向读取当前页面**已填的值**（如你在别的系统手填过）导入本地档案，仅覆盖空字段 |
| 📋 复制漏填项 | 把没填上的字段和目标值复制到剪贴板，逐项粘贴 |
| 🛠 复制字段报告 | 复制当前页面的字段结构（**不含填写内容**），发给作者改进匹配 |
| 🧹 清除高亮 | 移除页面红/黄/绿标记 |

## 六、各类控件怎么被处理

| 控件类型 | 处理方式 |
|---|---|
| 普通输入框 | 直接注入档案值 |
| 原生下拉 / 单选 | 按文本或编码值自动选中（支持"代码\|名称"选项） |
| 弹窗选择框（只读框+「选择」按钮） | 自动点开选择器 → 自动点选匹配选项；点选失败的红色高亮人工选 |
| 只读日期框（日历弹窗） | 直接注入 `YYYY-MM` 并模拟点开关闭，同步页面状态 |
| 联动下拉（选项随上级异步加载） | 填充后自动重试 3 次（约 1~3 秒） |
| 外语/计算机水平表 | 自动填「四级/六级 + 成绩 + 取得时间」；已填内容不覆盖 |
| 家庭主要成员表 | 按档案逐行填；行数不够自动点「新增一行」 |
| 学习工作经历表 | 逐行填（支持起始/结束时间分列与 2019-11 格式）；半填的行不覆盖 |
| 学术成果 / 奖励情况表 | 自动「新增一行」逐条填；空行优先，不覆盖你手填的数据 |
| 长文本域（经历/成果/获奖汇总） | 由档案列表自动合成 |
| 自我陈述 / 个人自述 | **不自动填**，请自行粘贴 |
| 验证码 / 密码 | 一律不碰 |
| 提交按钮 | **永不点击** |

## 七、「从本页提取档案」详解

### 7.1 它是干什么的

你在某个学校报名系统里**已经手填过**的信息（比如最早在南航系统里全部手填了一遍），点一下「📥 从本页提取档案」，工具会反向读取当前页面里已填的值，自动搬进本地档案并保存。以后去别的学校，这些信息就能一键填充，不用再敲一遍。

### 7.2 能提取什么

- 页面表单里**能被字段规则识别**的普通输入框、下拉框（自动取选项文字、去掉编码前缀）、文本域；
- **单选/复选组**：按你选中的那一项导入（如 性别=男、是否服从调剂=是）；
- **外语水平表**：按行内名称自动归类四级/六级成绩与取得时间（顺序打乱也不串）；
- **家庭主要成员表**：逐行提取，按姓名合并（同名更新、新名追加，**不会删除**档案里已有的成员）；
- **学术成果 / 获奖 / 学习工作经历 / 社会实践表**：按列头逐行提取，自动去重；
- **同源 iframe 内的表单**（有些学校把主表单嵌在框架里）。

### 7.3 适用范围（什么页面效果好）

- 页面字段**有清晰标签**（姓名、性别、手机号、本科院校……）的学校系统——绝大多数报名系统都满足；
- 表格类信息按标准列头（时间/单位/内容/名称……）呈现的页面；
- 已针对大连理工、西电、华东理工、河海、南航、东华、北邮、中南、海大等系统验证过。

### 7.4 局限性（可能提不到的情况，属正常）

1. **标签识别不到的字段**：字段标签用词特殊、或控件没有任何文字说明（纯代码框）——工具不敢猜，会跳过；
2. **弹窗选择框的隐藏编码**：如「学校代码+名称」成对字段，代码框是隐藏域、显示框只读——通常能取到名称文本，取不到内部编码（不影响后续填充，其它学校仍按名称填）；
3. **跨域 iframe**：浏览器安全限制，读取不了跨域框架里的内容（同源框架没问题）；
4. **验证码 / 密码**：按设计一律不碰；
5. **自我陈述等长文**：不自动提取（这些是你在档案里手动维护的多版本文本）；
6. **未选中的单选/复选**：组里一个都没选时，不写入"否"之类噪声值；
7. **已填过的档案字段不覆盖**：提取**只补空项**，你档案里已有的内容不会被页面上的旧数据冲掉（成员列表除外——按姓名合并更新）。

### 7.5 使用步骤与注意事项

1. 先登录目标系统，进入**已填好信息的**页面（只读/编辑页都行）；
2. 点悬浮面板「📥 从本页提取档案」；
3. 面板会显示提取清单（如「姓名 → 张三；手机号 → 139…」），同时自动保存；
4. 回档案编辑器核对一遍再用于其它学校。

> ⚠️ 提示：提取结果取决于"页面这一刻的状态"——页面被清空、还没保存、或字段在未展开的页签里时，对应信息就提不到。建议在页面显示完整时再点提取。

## 八、常见问题（FAQ）

**Q1：面板没出现？**
请确认扩展已启用、当前是普通报名网页，然后刷新页面重试。

**Q2：某字段没填上？**
正常现象。点「📋 复制漏填项」手动粘贴；同时点「🛠 复制字段报告」发给作者改进。

**Q3：更新了版本但感觉没变化？**
`edge://extensions` → 点扩展卡片「刷新」→ 再刷新报名页面（F5）。缺一不可。

**Q4：表格一直加行但不写数据 / 点了没反应？**
先按 Q3 确认版本已刷新。仍复现的话：点「🛠 复制字段报告」发给作者（报告不含个人信息）。

**Q5：某页填错了一格（比如姓名被覆盖）？**
手动改回正确值即可；之后的版本已修复此类问题，重新填充不会再覆盖已填内容。

**Q6：数据安全吗？**
所有档案只存在你自己浏览器的 `chrome.storage.local` 里，**不联网、不上传、无统计代码**。详见 `PRIVACY.md`。

**Q7：提交前检查？**
用「🩺 提交前体检」扫一遍必填缺失和格式错误，再人工核对提交。

## 九、数据与隐私

- 档案存储：浏览器本地 `chrome.storage.local`，仅本机可见；
- 权限仅两项：`storage`（本地档案）、`clipboardWrite`（复制漏填项/报告）；
- 「规则更新」默认关闭；开启后仅从 GitHub **下载**规则文件，不携带、不上传任何个人数据；
- 字段报告只含字段标签与结构，**不含任何填写内容**；
- 导出文件 `tuimian-profile.json` 请妥善保管，勿外传。
