# 我方 vs 巨能填 1.8.9：填写正确率与可填写范围差距 + 改进方案（F00 落档）

> 权威上下文：任务书 v10.1（sha256 见 `docs/dev-notes/v10-execution-ledger.md` L-000）。本文引用一律用稳定 ID。取证方式：双窗口（ZCode/DeepSeek）各自只读子智能体+本人复核，竞品目录未改动一字节。数字为 2026-09-11 实测。

## 1. 格局结论

- **可填写范围大体持平，无一方碾压**。我方：54 适配包（39 显式+15 蓝系生成，`src/core/adapter-packages.ts`）/ 69 唯一填报域名 / 去重校名 ~50；另有 8 平台壳+3 通配平台包+60 条通用规则（404 关键词）兜底未知页。竞品：识别面 107 域名/99 校/导航名单 88 校（**口径 A=导航宽度**），但正式填写授权（active 槽 S1_VERIFIED 且 `fill_enabled:true`）仅 **16 包**（**口径 B=可填授权**），实际可填面另靠 8 个手写 JS 适配器与蓝/复古/精致家族 writer 支撑。**两口径必须并呈**，任何单引"88 校"或"16 包"都是误导。
- **正确率是真实差距，形态是"踩坑知识"不是算法**：竞品 `page_protocol_fill.js` 单文件 82,082 行、85 writer（70 带校代号）、237 手写别名、40 硬编码域名，注释即事故复盘（"南航/东南/农大填分数后被踢回 /logon""农大综测被 EasyCheck 清空"）。
- **我方验证链反超**（不得改坏清单，VB 系列见任务书）：settle 稳定回读（`task-executor.ts:33-78`）、歧义 fail-closed+候选清单、码名成对回读阈值 65（`popup-binding.ts:157`）、conditionalRestore、身份证 ISO7064（`checker.ts:36-44`）、跨域 iframe（`all_frames:true`，竞品填写引擎 all_frames:false）、零桌面依赖（竞品离开 420MB Python 服务不可用，扩展自述"离开软件不可用"）。
- **我方最大盲区是"漏填不报"**（S3）与**零正确率基准**（P 系列卡补齐）；535 断言全布尔，无"应填 N/填对 M"口径。

## 4. 竞品能力边界（对标时别高估对手）

- 跨域 iframe：无解（all_frames:false+同源 contentDocument 遍历）；shadow DOM：双方都不穿透；富文本：仅 innerText；文件上传：仅 1 校；**保存/下一步/提交：竞品扩展同样永不执行**（E1212 硬闸，与 RD-2 同）；AI 未知页通道存在但**对用户硬关闭**（`ai_fill_is_public()`/E_AI_DISABLED）。
- 正确率保障与我方同类：写后即读回、选项成员 fail-closed（E1214 禁猜选）、任务↔页面绑定校验（E1206/1213/1215/1216/1217）、部分失败整页不 PASS（`fill_kernel.verify_readback`）。**它赢在场景知识，不赢在验证思想。**

## 5. 口径三纪律（RD-5/P8 支撑）

1. 竞品从未公布逐字段正确率 → 本文与后续一切交付**不产"vs 竞品 X%"**；其公开的是字段级缺口（gap_count 4596、53.2% 缺 control_kind、67% 选项未采集）——与正确率不同口径不可相减。
2. 竞品覆盖双口径并呈（§1 口径 A/B）；我方规模以 §1 实测为准（纠正早期"108 域名/102 校/73 包"的口径错误——把 `schools.ts` 名称表误计为覆盖）。
3. 冻结前双方所有数字 `liveVerified=false`；真实正确率基线由 D2 首产生。
