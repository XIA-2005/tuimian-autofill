# 改进实施任务书审查意见

日期：2026-09-09。审查对象：`C:\Users\m2694\Downloads\改进实施任务书-细化版(1).md`，文档内部版本为 v2。

## 结论

方向部分成立，但不宜原样交给实施 AI。保留“避免重复写入、保护已有值、唯一解析、稳定回读、回归证据”的主线，调整范围、顺序和具体规则。尤其不能借正确率改造重新引入“安全辅助填写/兼容体检”式大范围功能退化。

附件是待审查方案，不是本轮执行授权。本轮仅产生计划与审查文档，没有实施其业务代码修改、目录迁移或外部操作。

## 当前核查证据

- 项目版本 2.0.5，HEAD `97d78d3`。工作区原有未跟踪 `.deploy-xiaaaaa-v203/` 与 `docs/analysis/`，不可清理或打包进实现提交。
- `npm run typecheck` 本轮通过；未重新运行完整单测、构建或浏览器 E2E，不沿用历史全绿结论。
- 内存构建并调用当前 adapter-packages 模块：73 个内置包、109 个页面，配置非空 expectedFingerprints 的页面为 0。
- 合成文档实验：加入 `#tui-panel` 中的 input 会改变 fingerprintDocument；正常增加一行表格也会改变它。现有整页指纹不能直接充当每一步异步恢复的硬锁。
- 合成包实验：一个包额外声明无关 host 后，可能压过仅精确匹配当前 host/path 的包。现评分累加所有 host/path 数量，而非当前 URL 实际匹配分支的具体程度。
- 工作区根目录当前为 32 个 HTML 文件。文件数不等于学校数，不等于可执行填写样本数；scrape 下另有资产，应单独清点。

## 原任务书漏掉但应优先纳入的风险

1. `filler.ts` 用身份证区划兜底空籍贯/出生地/户口地，三者不是等价事实。应取消无来源确认的自动推断，不影响档案已有合法值。
2. `FIELD_LENGTH_CAPS` 静默裁剪普通字段，以及 standard-code-catalog 清除括号信息，都可能改变原始语义。应分别做边界样本，不只处理近似选项。
3. already-correct 不应加入扩展“本轮写入所有权”，否则用户点击清除本页时会清掉原本已有的正确值。
4. 字段锁定主要约束档案编辑/合并；不能误解为锁定档案值不能用于填网页。现有 E2E 就使用锁定字段填写。
5. 受控组件、用户同时手工编辑、同 id DOM 替换、迟到 frame 消息都是统一回读必须覆盖的行为。
6. DOM 成功、组件模型成功、服务器保存成功必须分别标注；本轮没有自动保存授权，不能承诺后者。
