## 2. 账本模板与中断续接

每卡记录：

```text
Task: Fxx / 子步骤
Status: pending | in_progress | failed | passed | blocked
Snapshot: HEAD + 实际改动文件内容哈希
Production entry: 实际入口及调用链
Changes: 改动文件及行为
Checks: 命令、退出码、用例、日志路径
Counterexamples: Q编号/新反例及结果
Coverage: v3 R编号及证明层级（纯单测/生产模块/扩展浏览器）
Remaining: 强制项未完成则不能 passed
Next: 下一处具体代码/验收入口
```

换对话先读本计划、审查报告、新账本和 git diff，只继续未完成卡。禁止把上次输出中的“全部绿”当当前代码证据。原 v3 的已验证实现可以复用，不重复制造第二套同名执行器。

最终向用户说明：完成哪些生产行为、真实运行哪些检查、哪些仅离线验证。若仍有一项主链强制验收未满足，标题必须为“整改未完成”，明确卡号与阻塞，不能声称全链 passed。
