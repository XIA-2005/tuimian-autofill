## 6. 我签字认领的审查者交付物（进入 F01 前必须完成）

按 **P6**，F01 的期望字段表由审查者复核签名后冻结。我接受该责任，但**同时指出一个独立性悖论并给出解法**：

- **悖论**：期望表由我（审查者）签名，而我又判定后续卡 → 我为自己的 oracle 当裁判，违反"作者与判定方必须不同模型"的精神。
- **解法（要求执行者配合）**：oracle **不得由我凭判断书写**，必须**从页面夹具 + 文档化映射规则推导**，即：
  1. 每条期望字段 = `{夹具页, 控件定位, 期望字面值, precision, 依据}`；
  2. `依据` 必须是**外部可核物**：夹具 DOM 的 `name/id/label`、页面 `maxlength/pattern`、或码表条目——不接受"我认为应该填这个"；
  3. 我复核的是"**推导链是否成立**"，不是"值好不好"；
  4. **推导规则文档 + oracle 全文交第三方（GPT）审计** —— 这是我无法自我完成的部分（见 §8）。
- **提交格式**：草案以 JSON 落 `docs/analysis/v10-review-2026-09-11/oracle-draft-F01.json`，我复核后签 `oracle-F01.signed.json`（含 sha256 与我的判定行）。
