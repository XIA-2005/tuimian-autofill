# 🎓 预推免填表助手（Edge 浏览器扩展）

辅助填写高校**预推免 / 夏令营**报名系统的浏览器扩展（Manifest V3，Edge / Chrome 通用）。

> **定位与原则**
> - 个人材料只保存在**本机浏览器**中，不联网、不上传；
> - 登录、验证码、短信验证**全部人工完成**，工具只在登录后的填表页工作；
> - 自动填写**基本信息类字段**（含家长/紧急联系人、证件类型、国籍、各类排名等），并可把获奖/科研/实践列表自动汇总进长文本域；**自我陈述**需人工选择版本粘贴；
> - **下拉/单选**（原生控件）自动选中；**弹窗选择框**（只读/禁用/隐藏输入框+「选择」按钮，点开页内浮层选取）自动点开选择器并点选匹配选项，点选失败的红色高亮留给人工；
> - **只读日期框**（点击弹日历）：直接注入"YYYY-MM"文本，并模拟点击收起弹层同步页面状态（无需再人工点一次）；
> - **外语/计算机水平表格**（表头为“外语水平/名称/类别 + 成绩 + 时间”结构）：首列为文本框或下拉选项都可填写；支持四级、六级、托福、雅思和其它考试，等级、成绩、日期始终成对，未知类型写入“其它”并保留备注；
> - **报考意向类字段**：在档案「报考意向」中登记当前学校（含申请学院/专业/研究方向/学位类型/意向导师）后，页面上的「申请学院/申请专业/申请类型/研究方向/是否有意向导师/是否服从专业调剂」等会自动推导填写；
> - **院校所在省市**：由本科学校名自动推导（内置高校→省份对照），也可在档案中手动指定；
> - **联动下拉**（选项随上级字段异步加载）：填充后自动重试 3 次（约 1~3 秒）；
> - **网络与规则更新**：默认**完全离线**；可在档案编辑器底部开启"规则更新"（仅下载规则文件，不含个人数据，见 PRIVACY.md）；
> - **家庭成员表格**（列头为"成员姓名+与本人关系"的裸表格）：自动按档案「家庭主要成员」列表逐行填充姓名/关系/单位/电话/政治面貌；
> - 普通“一键填充”不自动点击保存、下一步或提交；用户可主动开启“连续填写”，扩展只会在已验收适配包声明的页面完成回读校验后点击“下一步”，到上传、汇总、锁定或最终提交页立即停止；
> - 填完自动高亮：绿色=已填，红色=需人工，黄色=档案未填。

## 一、安装（Edge）

1. 打开地址栏输入 `edge://extensions` 回车；
2. 打开左下角「**开发人员模式**」开关；
3. 点击「**加载解压缩的扩展**」，选择本项目文件夹里的 **`dist`** 目录；
4. 工具栏出现图标后，点击图钉 📌 固定，方便使用。

> 更新代码后：重新执行 `npm run build`，然后回到 `edge://extensions` 点击本扩展卡片上的 **刷新** 按钮。

## 二、使用流程

1. **录入档案（一次性）**：点击扩展图标 →「打开档案编辑器」→ 填写个人材料 →「保存档案」。论文、专利、科研项目、竞赛、荣誉、实习、社会服务、学生工作/学习工作经历分八类保存；手工修改后自动锁定，可随时解锁。
   - 想先验证工具效果：点「🎲 生成测试数据」一键生成合法格式的随机假资料，到真实报名页面测试填充；确认无误后回到编辑器替换成真实信息。
2. **登录目标学校系统**：登录、验证码、短信验证全部人工完成（工具不会碰验证码和密码框）。
3. **进入报名填表页**：页面右侧会自动出现悬浮面板（若没有，点扩展图标 →「在当前页显示悬浮面板」）。
4. **选择填写模式**：只填当前页时点「⚡ 一键填充」；已支持的报名向导可点「🚀 连续填写（自动下一步）」，扩展会逐页补填、回读和纠错。
5. **人工收尾**：连续模式到未验收页或最终提交页会自动停止；检查红色/黄色高亮项，人工补填 → 人工核对 → 人工点最终提交。

## 三、悬浮面板按钮

| 按钮 | 作用 |
|---|---|
| ⚡ 一键填充 | 自动填写当前页面所有可识别字段 |
| 🚀 连续填写（自动下一步） | 在已声明安全导航契约的学校逐页填写；点击下一步前自动回读和纠错，绝不执行最终提交 |
| ⏹ 停止连续填写 | 立即终止自动翻页，不清除当前页面已经填写的内容 |
| 🏫 学校目录（报名入口） | 收录 80+ 所高校推免/预推免报名入口，直达报名系统 |
| 🩺 提交前体检 | 扫描必填缺失、格式错误（身份证/手机/邮箱/邮编）、一致性风险（出生日期 vs 身份证、排名 vs 人数），出清单点击定位 |
| 📥 从本页提取档案 | 把当前页加入累计爬取会话，先显示新增/冲突预览，确认后只合并新增内容并锁定；冲突保留原档案值 |
| 🧭 登录后会话爬取 | 仅对适配包白名单内的同源只读页面发起 GET，可再次点击取消；不调用保存、删除或提交接口 |
| 📋 复制漏填项 | 把未填上的字段和档案值复制到剪贴板（含自我陈述各版本字数速查），方便逐项粘贴 |
| 🛠 复制字段报告 | 复制当前页面**及所有子框架**的字段结构（**不含任何填写内容**），发给开发者以改进匹配规则 |
| 🧹 清除高亮 | 移除页面上的红/黄/绿标记 |

## 四、数据与隐私

- 档案存储位置：浏览器本地 `chrome.storage.local`，仅本机可见；
- 无统计代码，档案不联网、不上传；只有用户主动开启规则更新或点击已声明的登录后会话爬取时才会发起网络请求（详见 `PRIVACY.md`）；
- 字段报告不包含任何个人填写值，只有字段标签与结构；
- 导出文件 `tuimian-profile.json` 请妥善保管，勿外传。

## 五、发布与打包

```bash
npm run package   # 构建 + 全量测试 + 生成 release/tuimian-autofill-v1.0.0.zip
```

- 商店（Edge Add-ons / Chrome Web Store）上架文案、权限说明与审核清单见 `STORE_LISTING.md`；
- 隐私政策文本见 `PRIVACY.md`（Edge 上架必须填写，可直接引用）；
- 更新日志见 `CHANGELOG.md`；
- 手动分发：把 `release/*.zip` 发给用户，解压后按「一、安装」的"加载解压缩的扩展"步骤加载（或用户自行提交商店）。

### 调试参数（诊断用）

报名页面 URL 追加 `?tui-autotest=1`（用本地档案自动填充）或 `?tui-autotest=2`（用随机测试档案填充）并在页面写入结果标记，便于自动化回归与排查。

## 六、开发

### 目录结构

```
src/
├── manifest.json       扩展清单（MV3）
├── core/
│   ├── profile.ts      档案 V2、迁移、来源与锁定
│   ├── matcher.ts      字段匹配器（label/表格/父节点文本 → 档案字段）
│   ├── filler.ts       安全填充器（兼容 React/Vue 受控组件）
│   ├── importer.ts     反向提取（从已填页面导入档案）
│   ├── adapters.ts     声明式平台/学校适配包接口
│   ├── adapter-packages.ts 内置学校适配包与页面契约
│   ├── crawl.ts        当前页/登录后会话爬取与合并预览
│   ├── projection.ts   八类原子表到目标学校的投影
│   ├── storage.ts      本地存储
│   └── testdata.ts     随机测试档案生成
├── content/            页面内容脚本（悬浮面板 + 自动填充 + 消息处理）
├── background/         后台 Service Worker（跨 frame 聚合）
├── popup/              工具栏弹窗
└── options/            档案编辑器
```

### 如何适配新学校

1. 在目标页面的悬浮面板上点「🛠 复制字段报告」；
2. 把报告内容发给开发者（不包含任何个人信息）；
3. 开发者在 `src/core/adapters.ts` 中为该平台登记 URL 指纹与专属匹配规则，或在 `src/core/matcher.ts` 中补充通用关键词；
4. 重新构建后，同一平台的所有学校系统即被覆盖。

## 七、常见问题

- **面板没出现？** 点扩展图标 →「在当前页显示悬浮面板」；浏览器内置页面（`edge://`）和扩展商店页面不支持。
- **某字段没自动填上？** 属正常情况：先用「复制漏填项」手动粘贴，再用「复制字段报告」反馈改进。
- **下拉框/单选没选中？** 学校选项措辞与档案不一致时工具会保守跳过，红色高亮并列入漏填项，请人工选择。
- **换电脑/重装浏览器？** 先在编辑器「导出 JSON 备份」，新环境「导入 JSON」即可。
